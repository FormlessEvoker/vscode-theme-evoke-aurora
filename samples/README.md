# Evoke Aurora playground

Open these files in the Extension Development Host while editing the theme. They intentionally include common syntax scopes rather than application logic.

- `index.html` — HTML with embedded CSS and JavaScript
- `styles.css` — selectors, custom properties, at-rules, and values
- `app.js` / `app.ts` — modern JavaScript and TypeScript
- `data.json` — JSON keys, values, arrays, and `null`
- `sample.ex` — Elixir modules, maps, pipes, sigils, and guards
- `main.c`, `main.go`, `main.rs` — C, Go, and Rust constructs
- `notes.md`, `aurora.sh`, `aurora.diff` — documentation, shell, and Git diff scopes

# Palette

Open [palette.css](palette.css) to compare the named Evoke Aurora colors with VS
Code color decorators. The file is a development reference and is excluded from
the published extension.
